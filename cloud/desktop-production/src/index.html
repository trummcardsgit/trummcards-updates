Cloud-Verbindung einrichten

Diese App speichert hier nur die Supabase-Projektadresse und den oeffentlichen Publishable Key. Niemals Secret-, Service-Role- oder Datenbankpasswoerter einfuegen.

Im Supabase-Dashboard: Project Settings → API Keys. Nur der Schluessel mit sb_publishable_ ist erlaubt.

Persoenliche Anmeldung

Melde dich mit deinem Benutzer aus Supabase → Authentication → Users an. Nur das freigeschaltete Konto kann Lagerbuchungen durchfuehren.

Die Cloud-Verbindung ist fest auf das neue Produktionsprojekt eingestellt. Dein Passwort wird hier nicht gespeichert; die Sitzung bleibt im eigenen Cloud-Profil.

Einkauf ins Cloud-Lager buchen

Beim Einkauf wird ein neues FIFO-Los angelegt. Der Einzelpreis und der Gesamtpreis rechnen sich automatisch gegenseitig aus.

Verkauf im Produktivprojekt buchen

Alle Eingabefelder sind direkt bearbeitbar. Der Server verteilt den Einstand nach FIFO, verhindert Ueberverkaeufe und speichert die Buchung atomar.

Verkaeufe

Buchungen koennen storniert werden. Ein Storno stellt den Lagerbestand wieder her, entfernt die Historie aber nicht.
