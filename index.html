So funktioniert die Lagerlogik

Jeder Einkauf erzeugt eine eigene Lagercharge mit einem Stück-Einkaufspreis. Verkäufe werden automatisch den ältesten verfügbaren Chargen desselben Artikels zugeordnet (FIFO). Damit stimmt der Gewinn auch dann, wenn du dieselbe Karte später teurer oder günstiger nachkaufst.

Der Gewinn berücksichtigt Einkaufskosten, Verkaufsgebühren, tatsächlich bezahlten Versand und weitere Verkaufskosten. Der Lagerwert basiert auf Einkaufskosten, nicht auf geschätzten Marktpreisen. Alle Angaben vor Steuern.

Einkaufshistorie

Einkäufe aus Excel-CSV ins Lager buchen

Eine Zeile entspricht einer Einkaufsposition. Jede Zeile erzeugt eine neue Lagercharge; vorhandene Einkäufe bleiben bestehen. Beim Verkauf wird weiterhin FIFO verwendet. Bilder werden nicht über CSV übertragen: Danach kannst du sie im Reiter „Lagerbestand“ bei jeder Charge hochladen.

Pflichtspalten: Artikelname, Einkaufsdatum, Menge, EinkaufspreisGesamt. Datum: JJJJ-MM-TT oder TT.MM.JJJJ. Geldbeträge z. B. 12,50. Excel: „CSV UTF-8 (durch Trennzeichen getrennt)“ speichern. Semikolon und Komma als Trennzeichen werden unterstützt. Die Vorlage verwendet Semikolon.

Vor dem Buchen werden alle Zeilen geprüft und als Vorschau angezeigt. Fehlerhafte Dateien werden nicht importiert. Eine bereits importierte Datei nicht erneut importieren, sonst entstehen doppelte Einkäufe.

Datensicherung

Einkäufe und Verkäufe werden lokal gespeichert; Artikelbilder liegen zusätzlich in der lokalen Bilddatenbank dieses Programms. Die JSON-Sicherung enthält ab Version 1.3 auch deine Artikelbilder. Exportiere regelmäßig ein Backup und verwahre es an einem anderen Ort.

Beim Import werden die vorhandenen Daten einschließlich der Bilder durch die Sicherung ersetzt. Alte Sicherungen ohne Bilder bleiben kompatibel. Bitte vorher eine aktuelle Sicherung herunterladen.

Programm-Updates

TrummCards prueft beim Start und anschliessend alle 12 Stunden automatisch auf neue Versionen. Neue Versionen werden aus GitHub Releases geladen.

Vor jedem automatischen Programm-Update wird eine JSON-Sicherung deiner Einkaeufe, Verkaeufe und Artikelbilder in deinem Windows-Benutzerprofil abgelegt. Die Backup-Dateien bleiben auch nach dem Update erhalten. Fuer die Updatepruefung wird eine Internetverbindung benoetigt.

Achtung: Nicht signierte Windows-Installer koennen von Smart App Control blockiert werden. Updates werden nur angeboten, wenn du eine neuere Version in deinem hinterlegten GitHub-Repository veroeffentlichst.
